# shop-agent-saas
多租户门店AI Agent SaaS系统

## 项目简介
面向实体门店的企业级SaaS平台，基于Node.js + Express + MySQL + Vue3搭建，内置多AI Agent，为门店老板提供店铺数据分析、经营诊断、商业规划能力；配套Token计费、操作日志、权限管理、用户记忆持久化模块。
> 本项目为作品集项目，可部署给单门店使用，支持手机浏览器访问上传图片，具备企业级权限隔离与用量审计能力。

## ✨ 核心功能
1. 多租户架构：支持多家门店数据隔离，当前支持单门店落地使用
2. AI Agent 集群
   - 短视频文案Agent：生成门店短视频文案，配套图片解析、视频生成链路
   - 门店商业导师Agent：读取店铺历史经营数据，给老板输出经营分析、发展路径规划
3. 记忆持久化：存储用户全部决策、行为、店铺信息，AI可以基于历史数据持续分析门店
4. Token计量与后台管理
   - 完整LLM调用日志，记录每一次提问、回答、消耗token数量
   - 管理员后台：查看所有商户用量、审计对话记录；商户不可见后台审计数据
   - 额度管控，实现按量计费营收方案
5. 权限系统：区分管理员账号 / 门店商户账号，数据权限隔离
6. 移动端适配：手机浏览器可上传图片、使用全部基础功能

## 🛠 技术栈
- 后端：Node.js + Express
- 数据库：MySQL
- 前端：Vue3
- AI能力：LLM大模型API，支持扩展RAG知识库
- 版本管理：Git + GitHub
